# Tandoğdu Tekstil website

This is a static, bilingual corporate website. Double-click `preview.cmd` to open the local preview with clean page addresses such as `/products/` and `/tr/products/`. Keep the terminal window open while browsing; close it to stop the preview.

You can also open `index.html` directly for the English home page or `tr/index.html` for the Turkish home page. Direct file browsing shows `.html` in the address bar; the preview launcher uses clean addresses. Each navigation item opens a separate page in the selected language.

## Pages

- Home / Anasayfa
- About us / Hakkımızda
- Products / Ürünler
- Production / Üretim
- Delivery / Teslimat
- Showroom
- Certificates / Sertifikalar
- Contact / İletişim

The optimized website images are in `assets/`. The original photographs remain in `img/` in the working folder.

## Before publishing

- Add the approved corporate logo, if available. The current wordmark is a temporary typographic treatment.
- Provide and approve the public email address and phone number. The contact form currently copies a project brief; it does not send data.
- Provide certificate documents and approve the exact names and claims to display on the certificates page.
- Confirm the final wording of the two-week turnaround statement for applicable projects.

The site does not require a build step or external JavaScript libraries. It uses Google Fonts with system font fallbacks.
